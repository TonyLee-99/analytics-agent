## File a 311 FOIA Request
The Freedom of Information Act (FOIA) is a state law that provides citizens with access to public records.  Each City department is a separate agency responsible for maintaining its own records, so requests should be submitted to the department that maintains the records you want.
All Freedom of Information requests should include the following information :
The name, mailing address and day time phone number of the requester;
A description of the records that are being requested;
Location and time frame parameters;
Please provide details and specifics about the information you are requesting, including location, date and/or date range.  Also indicate in your request how you would like the information sent to you (e.g., fax, email, regular mail).
