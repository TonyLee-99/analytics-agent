maria · mixed · author
What is CDOT's stated target for pothole repairs, and what was the actual median days to close for completed pothole complaints created in 2025 (completed only)?
answered · route both
CDOT's stated target is to respond to pothole repairs within 7 days S2. Under the governed metric `median_days_to_close_completed` (median days from creation to closure, completed requests only), the actual median for completed "Pothole in Street Complaint" requests created in 2025 was about 12.9 days.

That median is roughly 5.9 days above the 7-day target. The target comes from a performance-metric dataset last updated in 2014 S2, and that dataset reports average days, not median, so the comparison is approximate. The weekly target column in S1 has no values in the provided sources.
  • S1 Performance Metrics - Transportation - Pothole Repair portal-sbt5-2ec8:944-1351
  • S2 Performance Metrics - Transportation - Pothole Repair portal-sbt5-2ec8:0-1144
SQL run as cu_maria (departments CDOT)
SELECT * FROM (
WITH m_median_days_to_close_completed AS (
  SELECT percentile_cont(0.5) WITHIN GROUP (ORDER BY days_to_close) AS median_days_to_close_completed
  FROM (
    SELECT r.sr_number, r.sr_type, r.dept_code, d.department, r.origin, r.status, r.is_open, r.is_canceled,
           r.is_duplicate, r.created_at, r.closed_at, r.community_area, ca.community_area_name,
           ca.population_acs, r.ward,
           EXTRACT(EPOCH FROM (r.closed_at - r.created_at)) / 86400.0 AS days_to_close,
           b.benchmark_days
    FROM wh.service_request r
    JOIN wh.department d ON d.dept_code = r.dept_code
    LEFT JOIN wh.community_area ca ON ca.community_area = r.community_area
    LEFT JOIN wh.request_benchmark b ON b.sr_type = upper(r.sr_type)
  ) AS m
  WHERE (status = 'Completed' AND closed_at IS NOT NULL)
    AND created_at >= TIMESTAMP '2025-01-01'
    AND created_at < TIMESTAMP '2026-01-01'
    AND sr_type = 'Pothole in Street Complaint'
    AND dept_code = 'CDOT'
)
SELECT median_days_to_close_completed
FROM m_median_days_to_close_completed
) AS _guarded LIMIT 1000

      How does the Graffiti Removal Program work, and how many graffiti removal requests were created in 2025?
      answered · route both
      How the program works: The Department of Streets and Sanitation offers free graffiti removal to private property owners S1S2. Its "blast" trucks use baking soda under high water pressure on brick, stone, and other mineral surfaces, and its paint trucks cover graffiti on surfaces such as metal or wood S1. Residents, block clubs, and other groups report graffiti or request removal by calling 3-1-1 S2S4. If a cleaned building is hit again, the department aims to return quickly S1. A performance metric sets a target of 10 days to complete a request, though that dataset was last updated in 2012 S5.

      2025 volume: 94,893 graffiti removal requests were created in 2025 (Jan 1, 2025 to Dec 31, 2025). This uses the governed metric "requests," which counts all requests created, including duplicates, as the City's portal does [DATA].
